# Real buy integration gate

Official resources: https://usebuy.ai/docs and https://github.com/celo-org/buy-skill

1. Confirm current documented CLI/MCP invocation and versions.
2. Locate a legitimate Instagram public-profile/post data service in the live catalog. Do not assume availability.
3. Record exact service identifier, price, permitted usage, required fields and schema.
4. With team approval, use a dedicated low-balance wallet and perform one minimal paid request.
5. Verify response fields and transaction evidence on Celo mainnet.
6. Implement a server-only adapter with explicit quote, spend ceiling, idempotency and ambiguous-settlement handling.
7. Replace mock data only after successful verification; keep demo mode visibly labeled.
8. Add agent identity registration and submission evidence according to current hackathon rules.

No endpoint or paid call is implemented in this starter.
